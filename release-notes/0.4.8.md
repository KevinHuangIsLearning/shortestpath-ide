# ShortestPath IDE 0.4.8

## 更新

- Compact Mode 默认开启，开关移至「ShortestPath IDE 设置 → 外观与保存」。导航支持左右箭头和触控板滑动切页，滑块跟随悬停与手势移动；展开时覆盖 Command Center，避免按钮被挤压。
- 有新版本时，「更新」按钮直接显示在标题栏右侧，紧凑导航收起时也能看到。
- Ctrl + Tab 和 Ctrl + Shift + Tab 按最近使用顺序切换浏览、做题和草稿等多标签页面，并自动进入标签所在页面。
- 整理浏览标签栏、分屏与新建标签入口；收藏区域支持展开、收起，并用星标和箭头显示当前状态。
- 内置浏览器集成 Dark Reader，支持随主题自动切换、检测网页已有深色主题和排除站点；相关选项可在 ShortestPath IDE 设置中调整。
- 内置 AtCoder Better 和 Codeforces Better，并在 ShortestPath IDE 设置中提供各自的开关。
- macOS 内置浏览器支持触控板左右轻扫前进、后退：边缘箭头随手势显示，达到阈值后松手切换，回拉可取消。
- 修复浏览区域高度为零、标签已打开却不可见的问题；修复组合题目标签中的刷新、缩放和只读网址选择复制，以及标签栏顶部留白。
- Sketchboard 支持多个草稿标签，以及存放在 IDE 存储目录中的文件和文件夹；支持行内命名、重命名和拖拽移动，停止操作 1 秒后自动保存。清空、导入、导出移至文件右键菜单，可从标签栏打开代码旁绘图。
- SPOJ 题目预览支持 50%–200% 缩放，点击百分比恢复 100%，刷新后保留比例；题面、提示、评测和解题报告同步缩放。
- SPOJ 网页提交正常时保持在「做题」；需要安全认证时显示「浏览」，提交结果返回后回到「做题」。
- SPOJ 评价改为「夯 / 普 / 拉」，显示表情、文字和人数；首次 AC 评价弹窗提供「稍后再说」。点赞先更新本地显示，再同步网站。
- 修复题目链接重复打开和解题报告参考代码无法滚动的问题；缺少本地评测工具时仍可查看、复制官方样例。题目折叠时显示箭头，悬停标题显示下划线，让展开入口更清楚。
- Dashboard 打开或切回时自动刷新，删除、重命名源码后同步题目记录；移除 Activity Bar 中的空 Dashboard 侧栏入口，保留独立页面。
- 修复切换不同目录下的同名文件时 Judger 未刷新，以及侧栏更新抢走编辑器焦点的问题。

## What's New

- Compact Mode is enabled by default, with its toggle under ShortestPath IDE Settings → Appearance and Save. Use arrows or trackpad gestures to switch pages, with a highlight that follows hover and gestures. Expanded navigation overlays the Command Center so navigation buttons are not squeezed.
- When an update is available, the Update button appears on the right of the title bar and remains visible while compact navigation is collapsed.
- Ctrl + Tab and Ctrl + Shift + Tab switch between browsing, solving, sketchpad, and other multitab pages in recent-use order, opening the page that owns the selected tab.
- Refined browsing tabs, split views, and the New Tab entry. Favorites can expand or collapse, with a star and arrow indicating their state.
- Integrated Dark Reader into the browser, with automatic theme switching, detection of existing dark website themes, and site exclusions. These options are available in ShortestPath IDE Settings.
- Bundled AtCoder Better and Codeforces Better, with separate switches in ShortestPath IDE Settings.
- On macOS, swipe left or right on the trackpad to navigate browser history. Edge arrows follow the gesture; release past the threshold to navigate, or pull back to cancel.
- Fixed invisible browser tabs caused by a zero-height browsing area. Also fixed reload, zoom, and selection and copying of locked URLs in paired problem tabs, plus the gap above the tab bar.
- Sketchboard supports multiple drawing tabs and files and folders stored in IDE storage, with inline naming, renaming, drag-and-drop moves, and autosave after one second of inactivity. Clear, Import, and Export are in the file context menu; Draw beside Code is available from the tab bar.
- SPOJ problem previews support 50%–200% zoom. Click the percentage to reset to 100%; zoom persists across refreshes and applies to statements, hints, judging, and reports.
- SPOJ web submissions stay in Solve normally, show Browse when security verification is required, and return to Solve after the submission result arrives.
- Updated SPOJ ratings to the new “夯 / 普 / 拉” labels, with emoji, text, and counts. The first-AC rating dialog offers Later. Likes update locally before syncing with the website.
- Fixed duplicate problem-link opening and scrolling in editorial code. Official samples remain available to view and copy when local judging tools are unavailable. Collapsed problems show an arrow, and titles are underlined on hover to make the expand action clearer.
- Dashboard refreshes when opened or revisited and reconciles problem records after source deletion or renaming. Removed its empty Activity Bar sidebar entry while keeping the standalone page.
- Fixed Judger failing to refresh when switching between same-named files in different folders, and sidebar updates stealing editor focus.

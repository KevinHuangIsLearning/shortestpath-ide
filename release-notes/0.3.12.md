# ShortestPath IDE 0.3.12

## 更新

- 精简内置组件：移除不面向竞赛编程的 PDF 预览，以及 LaTeX、YAML、Shell、Makefile、dotenv 和 Prompt 文件语言支持；Python 支持保留。
- 简化设置新增“使用插件市场”：默认关闭扩展入口；启用后使用 Open VSX，并在首次启用前展示第三方市场免责声明。
- 修复插件市场首次查询时可能导致扩展页无法使用的问题。
- 简化设置新增“显示语言”：可查看当前语言，并通过 VS Code 原生语言选择器切换后重启生效。
- 首次使用向导、竞赛编程设置、CPH 配置、工具链诊断与 ShortestPath OJ 的题面/题解界面现会跟随显示语言；已提供简体中文和英文文案，题目、样例、提示及题解原文不会被翻译或改写。
- 内置简体中文语言包更新至 `1.131.2026072717`，同步 VS Code 1.131 的中文翻译。
- 移除状态栏中的 Copilot 项，并修复“关于”窗口中版本信息的排版错位。
- 内置 Flintmark，并将所有 Markdown 文件默认使用其所见即所得编辑器打开；仍可通过“重新打开编辑器方式”或编辑器关联设置切换。
- 内置 PDF Viewer，打开 PDF 题目时默认在 IDE 内阅读；仍可通过“重新打开编辑器方式”切换查看方式。
- “检查更新”现在会明确显示当前已是最新版本、可用更新版本或检查失败。

- 此版本不是可选更新，请及时升级。后续更新频率将降低。
- This is not an optional update; please upgrade promptly. Future updates will be less frequent and will focus mainly on necessary fixes and important features.
